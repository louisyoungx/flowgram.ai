# FlowGram Desktop 设计与动效规范

产品界面以用户指定的 [Claude Storybook](https://claude-storybook.bystanderss.chatgpt.site) 和 [Claude MCP Apps 社区设计文件](https://www.figma.com/design/iAyueTdyOjxZZhNpRpbCQY/MCP-Apps-for-Claude--Community-) 为长期依据。它们是本项目选定的参考，不代表 FlowGram 与参考产品有品牌关联。FlowGram 保留自身名称和官方标志。

已读取 Figma 桌面组件 `849:18137`，并对照其截图、颜色、14/16/20px 字级、8/10/12px 控件与容器圆角、表面分层和轻边框。文件链接 `0:1` 是封面，`838:2412` 是推广素材页，不将其当成工作区布局原样复制。

## 基础 token

在 `apps/desktop/src/styles.css` 定义语义、尺寸和动效 token；配色由 `apps/desktop/src/lib/themes.ts` 集中提供，组件复用 token，不分别发明主题。

| 用途 | 浅色值 |
| --- | --- |
| 侧栏 / Surface 0 | `#f5f5f3` |
| 主内容 / Surface 1 | `#fcfcfb` |
| 卡片、输入框 / Surface 2–3 | `#ffffff` |
| 画布纸面 / Figma bg/100 | `#faf9f5` |
| 文字 / 弱文字 | `#20201e` / `#6b6863` |
| 主强调 / 悬停 / 选中底色 | `#d97757` / `#cc5a36` / `#fbf3ef` |
| 轻边框 | `rgba(31,30,29,.15)` |

常规 UI 使用 Inter 与系统无衬线回退；操作文字 13–14px、正文 14–16px、设置标题 20px。数值与结构化输出使用等宽字体。消息流的正常进度、成果入口、待办操作与发送按钮使用中性色，链接以文字下划线表达可点击性。仅明确失败使用错误红色，并配合图标和状态文字；“结果待核实”使用中性色和提示图标。暖色强调用于少量界面操作反馈；画布选中、框选与键盘焦点使用独立的主题 token。节点类型颜色仅用于小面积图标，不铺满卡片。

控件圆角 8px，节点与轻容器 10px，模态框 14px，Composer 20px。浅阴影使用 `0 4px 20px rgba(0,0,0,.035)` 与轻内描边。空间层级依赖表面、间距和边框，不堆叠多重投影。

## 布局与尺寸

```text
会话入口：项目侧栏 │ 会话 │ 按需工作流 / 运行工作台
工作流入口：项目侧栏 │ 独立工作流编辑器
工作流内部：画布 │ 按需节点配置；下方按需运行结果
设置页：返回工作区 / 分类导航 │ 分类内容
```

- 单一项目侧栏 200–340px；会话并排时默认 420px、范围 320–640px，右侧工作台至少保留 320px；节点配置默认 400px、范围 320–520px，受窗口实际剩余空间约束，空间不足时使用展开编辑。节点面板与组件细节见 [节点面板设计](node-panel-ui-and-components.md)。
- 分隔线支持指针捕获、方向键调整、双击复位，并保存到本机布局设置。
- 底部运行结果支持从标题栏关闭、从画布工具栏重新展开，记住可见性与独立的高度设置。隐藏释放全部垂直空间，保留结果内容与画布实例；主动试运行或查看运行记录时展开，后台执行状态刷新不抢占画布。关闭后焦点返回工具栏开关，恢复默认布局时重新显示面板。
- 拖拽时直接跟手，禁止宽度补间或自动缩放画布；设置中可以恢复所有默认尺寸。
- 打开设置保留后台工作区和编辑器实例，返回时恢复原有画布与对话上下文。
- 项目侧栏同时展示工作流与会话列表，顶部快捷入口提供新建、搜索、运行记录和项目资源。会话在左，工作流工作台在右；侧栏直接打开工作流时使用独立编辑器，不带会话。项目、会话、工作流与运行的归属和页面切换以 [项目工程与 App 信息架构](agent-workflow-app-information-architecture.md) 为准；当前文档、输入引用、运行回看分别保留状态。
- 节点卡片采用「类型图标 + 名称 / 类型 → 业务配置摘要 → 输入输出 / 执行状态」；不再把类型英文大写作为主标题。

## 主题设置

明暗模式（跟随系统 / 浅色 / 深色）与主题配色独立保存。按顺序提供石墨、纸墨、暖砂、海湾、松林、玫瑰、鸢尾、琥珀 8 套配色，每套具备浅色与深色版本；石墨为浅色和深色的默认配色，恢复默认主题也回到石墨。纸墨是原 FlowGram 配色，位于第二位，不作为默认值。浅色、深色分别选择，系统明暗变化时直接应用对应版本。配色覆盖界面表面、文字、强调、错误、画布点阵、连线、节点、选择与键盘焦点，节点类型颜色也有独立明暗值。

设置使用共享 `ui/visual-choice` 预览卡，基于原生单选组，支持 Tab、方向键和独立焦点轮廓。预览呈现侧栏、画布与节点，不把不同配色简化成色点。选择即时应用并持久化；恢复默认只重置两套配色，保留明暗模式、语言、动效和布局。启动渲染前应用主题，监听系统明暗与跨窗口存储变化；不重建 React 工作区或画布，不重播入场动画。所有内置配色的正文及次要文字在主要表面满足 4.5:1，节点选择描边在画布和节点表面满足 3:1，由主题测试回归。

单色 SVG 资产使用共享 `ui/asset-icon` 的遮罩继承文字颜色，避免深色主题中残留固定黑色图标；官方彩色标志继续原样展示。

## 动效约束

参考 Storybook 的短反馈与阻尼感，按场景取值，不为每一行添加入场动画。

| 场景 | 规则 |
| --- | --- |
| 颜色与微反馈 | 60ms 微反馈 / 120ms 吸附 |
| 浮层与设置页进入 | 200ms 控件展开 / 300ms 设置页，小幅位移与透明度 |
| 强调揭示上限 | 350ms，不用于工作区尺寸拖拽 |
| 缓动 | `cubic-bezier(.165,.84,.44,1)` / `cubic-bezier(.19,1,.22,1)` |
| 拖拽 | 无补间、无回弹、无过冲 |
| 流式回复 | 原地追加，禁止每个 chunk 重播入场或平滑滚动 |
| 画布 | 保存、参数应用和侧栏调整都保留同一实例与视口；仅首次打开或用户点击适应画布时 fit |
| 无障碍 | 遵循系统 reduced motion；设置可单独减少动态效果 |

避免 `transition: all`、全局滚动动画、布局尺寸与位移同时驱动、用闪烁掩盖重新挂载、反复出现的 loading 空白。

## 验收

消息流使用稳定的 Turn / Item 身份：文本追加和转为最终答复保持同一 DOM 节点；工具开始到结束在同一行更新。历史默认收起过程，正文、用户补充和成果保持原有因果顺序。仅当用户停留在底部时跟随追加；向上阅读不抢滚动，提供回到最新入口。展开工具只显示有限长度的参数与结果预览。待办和等待接收的本轮补充分开标记，发送与停止为独立操作。遵循 [对话信息架构](conversation-information-architecture.md)。

修改任何桌面视觉功能时，检查默认 / hover / active / focus / disabled / error 状态，使用真实运行数据截图。重点回归保存前后画布缩放、连续拖拽、设置往返、流式输出与减少动态效果模式。节点必须有真实配置和 Rust 执行器，并用覆盖不同数据形态与控制语义的节点组合验证。

## 控制流端口与执行样本

画布禁止使用 FlowGram dynamic port、DOM 端口扫描或测量驱动的端口布局。端口列表与坐标由配置显式生成，使用 `WorkflowNodePortsData.updateAllPorts` 更新静态定义，`useDynamicPort` 固定为 false。端口模型缓存排除节点位置与普通字段输入，拖拽不重新生成端口模型。

多个出口或入口按行显示业务名称，端口位置与行对齐；分支 ID 保持稳定，重排同时更新对应汇合入口顺序。已连接出口的删除入口禁用，并说明先改接或移除连线。新增结构化分叉同时创建对应汇合，空路径可继续插入节点。循环容器显式使用引擎计算的尺寸，标题、边界和内部节点一起显示。

节点面板通过“运行样本”选择具体执行实例，显示分支路径和轮次。未选择实例时只展示工作流外层样本。实例选择不改动节点配置，也不触发画布重新挂载或自动适应视图。汇合节点提示使用完整试运行，单节点测试按钮禁用。

## 界面语言与内容边界

设置「通用」首项为界面语言，使用共享 Select 浮层组件，提供跟随系统、English、简体中文；语言名称使用各自母语。未指定时使用系统语言，不支持的系统语言回退英文。选择保存在 `flowgram.language`，更改后立即更新界面与文档 `lang`，不刷新页面、不重新挂载画布，不触发工作流保存。系统语言变化与同源窗口偏好变化会同步生效。

导航、设置、消息流状态、工具展示名、节点目录、字段标签/说明/选项标签和执行诊断使用共享翻译目录 `apps/desktop/src/lib/locales/messages.json`。静态元数据通过 `localized` 按读取时的语言呈现；只翻译展示字段，节点类型、编辑器类型、字段路径、端口 ID、枚举值、Schema 和执行默认值保持原值。新增文案必须补齐中英文，并验证语言切换不改变编辑器种类或选项值。

项目名、会话名、节点名、分支名、用户消息、模型回复、提示词、输入输出与已保存的工作流是用户内容，切换界面语言不翻译、不覆写。Agent 默认系统提示词、工具描述、共享节点契约与后端诊断固定使用英文；Agent 按用户输入或明确指令决定回复语言。原始工具参数和返回 JSON 保留原始契约，UI 只在状态及诊断展示处本地化。


## 画布主题与选择控件

画布背景、点阵、节点表面和普通连线分别使用 `--surface-canvas`、`--canvas-dot`、`--surface-node`、`--canvas-line`。暗色值为 `#1b1c1a`、`#41433e`、`#242522`、`#898c83`。点阵间距 28px、半径 0.7px 随缩放变化；填充引用主题 token，描边透明，禁止继续使用引擎的浅色默认描边。主题切换通过 CSS 变量更新同一画布，不重建编辑器或重置视口。

所有可见枚举选择统一使用 `components/ui/select.tsx`，基于 [Radix Select](https://www.radix-ui.com/primitives/docs/components/select)。组件负责浮层定位、边界避让、滚动、已选勾选、禁用项、方向键/Home/End/输入检索、Escape 关闭和焦点返回。默认控件用于设置和表单，ghost 变体用于消息输入区的紧凑选择。短淡入遵循减少动态效果设置；浮层只在打开时出现。

调用方提供稳定 `value`、`options` 和 `onValueChange`，不构造伪造的浏览器事件。空字符串是允许的业务值；内部编码仅用于底层组件，保存与回调始终保留原值。文案跟随界面语言更新，选项值不得随翻译改变。菜单通过 Portal 渲染在应用浮层中，避免被节点面板裁切；对话框内仍保持键盘焦点。ESLint 禁止桌面源码新增可见原生 `<select>` / `<option>`，新页面必须复用原子组件。

## 节点交互与命令

画布单击选择，双击或 Enter 打开配置；面板已经打开时，单击其他节点切换目标，拖拽不切换目标。空白单击只清空选择，保留配置上下文；多选在已打开面板中展示批量操作。选中集合来自引擎 SelectionService，配置目标、重命名事务和添加意图由工作区管理。禁止常驻标题输入框或将省略号当成配置按钮。

画布 F2、节点菜单“重命名”、配置标题旁铅笔使用共享 `ui/inline-rename`。Enter/有效失焦确认，Escape 取消，中文输入法组合期间 Enter 不确认。空名称就地校验。一次确认是一条修改与撤销记录；展示名称不改变 ID 和引用。节点菜单、右键和快捷键调用同一组命令，菜单使用共享 `ui/command-menu`；禁用动作显示原因。

添加意图显式携带位置、作用域、源端口或原连线。工具栏打开完整节点库，画布 N、空白双击、端口加号和连线加号打开紧凑搜索；两者共用节点目录和添加事务。已有唯一连接的出口加号插入原连接，不再生成同出口的重复连线。端口选择不唯一时必须明确选择，确认前不更改图。搜索词不隐式修改节点操作。循环内添加使用明确作用域，拖过容器边界不自动改变作用域。

复制包含容器子图以及分叉至配对汇合的完整区域，只保留集合内部连线。粘贴重建节点 ID、内部引用和模板引用，常量数据不改写。外部引用不能直接带入其他工作流或作用域；边界节点不可独立复制或删除，被其他节点引用的集合必须先解除引用。结构变更与重命名由引擎历史事务统一记录。取消或无效落点的连线改接保留原线。

键盘优先交给输入框与顶层浮层，随后处理画布命令。支持 F2、Enter、复制/剪切/粘贴、副本、Delete、撤销重做、同作用域全选与方向键导航。Escape 只退出当前层；节点库里的端口 Select 先关闭自身，再退出节点库。结果入口打开输出页签并携带具体执行实例。菜单、选择标记、端口热区和面板切换遵循现有主题、静态端口、减少动态效果与保持视口规则。

连线插入与下游节点重叠时，将目标及其下游整体右移留出空间，位置变更与增点、改线属于同一撤销事务，不自动缩放画布。工作流同步必须使用引擎 operation 服务，不能用会抑制增点历史的 document 数据加载接口代替；撤销重做期间暂缓 React 状态发布，只发布事务结束后的完整图。

## 画布选择状态

选择状态使用配色对应的低饱和选择色，与纸面和节点表面保持一致。默认石墨的浅色 / 深色分别使用 `--canvas-selection-stroke` `#707070` / `#b5b5b5`；多选边界由该色与画布色混合，焦点由该色与前景色混合。拖动框选填充约为相应选择色的 7%，节点外晕约为 11%。其他配色共用相同语义和生成规则。

节点选中使用细描边与一圈轻外晕，保留原节点表面。拖动中的框选框使用 1px 实线、6px 圆角和淡填充；松手后的多选边界使用透明内部、1px 次级描边与 14px 圆角，不再铺大块蓝底，也不画暗示缩放能力的控制点。键盘焦点使用单独的 2px 外轮廓与 4px 间距，普通按钮 focus-within 不再冒充节点选中。连线的悬停、选中和拖动使用同一选择色系，错误颜色保持独立。

桌面样式在 `.workflow-canvas-interactions` 内覆盖引擎选择变量和选框类，消除默认紫色透明填充与硬编码 `#f0f4ff` 背景。只改变视觉，不替换选择层、不改变命中范围、框选算法、图数据或视口；主题切换直接更新 CSS 变量。框选尺寸跟手，不加布局动画。订阅引擎框选阶段更新 `data-selection-gesture`，拖动时只显示活动框选框，松手后再显示多选边界，避免两层框重叠；不通过 React 重渲染或端口测量驱动该反馈。

## 工程工作区与头部

窗口只有一个当前项目，使用单一侧栏，不设外侧图标导航。顶部依次为项目菜单、搜索和收起；下方操作区仅保留带图标的新聊天、搜索和项目资源入口；再展示工作流与会话两组列表。工作流分组右上角放更多菜单和 +：运行记录收进更多菜单，新建工作流使用 +；会话分组的 + 使用“新聊天”名称。操作区不再重复主页、新建工作流和运行记录入口。两组始终可见，不随内容区目的地互相替换。工作流总览页承载当前项目的流程与模板，保留为项目初始页和关闭独立编辑器后的落点；分组标题是静态标签，不再隐藏页面跳转。具体工作流条目仍直接进入编辑器。类别图标只出现在“工作流”和“会话”分组标题左侧，具体条目不重复图标，名称与分组标题文案对齐；条目尾部只在运行中显示真实状态。设置固定在侧栏底部，列表独立滚动，不额外增加品牌行或状态入口。项目菜单收纳最近项目、新建、打开、导入和导出；每个项目行的更多菜单提供重命名、查看详情和删除，无需切换当前项目；路径仅在项目详情中显示，支持复制与在文件管理器中显示。

项目导入、导出放在项目切换菜单的工程操作组，不增加侧栏常驻入口。复用共享 Dialog、Input 和 Button：导入先选择项目包，再展示工作流 / 资源数量、历史范围、名称和可选保存位置；提交前不创建工程，成功后切到新副本主页。导出明确是已保存内容，并提供会话与运行记录选项，桌面版调用系统保存窗口。处理期间禁止重复提交，文件无效时就地显示本地化错误；成功与失败不改变原项目的草稿或画布。

各内容区域使用同一 48px `WorkspaceHeader` 并水平对齐。移除全局项目 / 会话面包屑和常驻连接成功文字。会话标题只出现一次，右侧放更多操作与工作台开关；工作流头部是名称或文档页签、次要保存状态、更多操作和关闭 / 收起。画布工具栏单独承载操作，窄宽度时允许换行。版本信息在运行来源中展示，编辑标题旁不重复堆放。侧栏收起时，项目菜单只在当前主要内容头部出现一份。

会话与工作流是两种入口。会话工作区固定会话在左、工作台在右；右侧按需打开工作流或运行。侧栏、搜索和工作流列表打开流程时进入独立编辑器，不继承可见会话。通过“让助手修改”明确选择新会话或已有会话，并附加工作流引用。快捷入口只切换视图，保留草稿、输入队列和已挂载画布。

读取、创建、保存、校验、运行或节点测试的实际成功工具调用，携带具体工作流 ID 时，自动在会话右侧打开或复用文档。列目录、节点发现、工具参数流、失败和历史快照恢复不触发自动打开。用户切换文档后，同轮后台操作只将新目标加入文档列表；用户收起工作台后，同轮不自动撑开。下一轮恢复自动跟随；输入引用仍只能通过显式动作改变。每段会话独立恢复工作台页签、当前文档与开合状态。

工程打开失败留在打开对话框内，可重试；后端在取得工程后才登记，不修改当前项目。其他操作错误使用带项目范围的局部通知，不新增横贯顶部的错误标题层。连接状态在设置页面按需查看。

所有宽度拖拽直接跟手，不加布局补间。隐藏文档使用 inert 与 visibility，编辑器不因入口或主题切换重新初始化。


## 会话内容与输入区

消息与输入区共用最大 800px 的内容容器，窄会话区域使用 16px 消息边距、12px Composer 边距。textarea 两行起步，高度 48–160px，随内容和区域宽度立即调整，不做高度过渡；超长输入内部滚动。模型与工作流引用位于输入底栏，卡片只保留轻描边与克制的 focus ring。

运行中内联显示过程，连续工具调用以紧凑摘要呈现，工具组和原始参数 / 结果默认收起。正常结束时过程收起，最终回复和成果入口保留；失败、中断与最新无最终回复轮次默认展开。纯文本轮次不显示空过程开关，完成状态不再在底部重复出现。折叠、历史恢复、滚动和补充输入的规则见 [会话信息架构](conversation-information-architecture.md)。


## 复杂项目的运行检查

运行输入从起始节点的 Schema 和显式 default 生成；整数使用数值输入，重新打开试运行保留草稿并补充新字段，不再填入固定演示消息。运行详情按需展示依赖版本与内容哈希，过程事件分页追加。画布只投影当前工作流的节点状态，终态从独立的节点状态摘要读取，不依赖第一页过程事件是否包含结束节点。

## 部署模块

部署属于全页设置，包含发布、凭证和运行服务三个页签，作用域覆盖所有已登记项目。项目侧栏不增加服务入口，设置导航不增加“当前项目”分组。工作流发布按钮带入所属项目，进入同一个部署模块；返回工作区保留原会话、草稿、画布实例和视口。

发布列表使用有边界的卡片；草稿和已发布分组展示。卡片代表一个项目的持续发布配置，新版本和不同运行目标归入同一卡片，不按版本复制卡片。卡片显示所属项目、公开工作流数量、目标、环境、当前部署版本及更新时间；这些是最近确认的部署事实，不冒充持续在线监测。详情从目标读取实际状态，连接失败时明确显示未确认，不拿草稿或最新版本替代线上版本。

新建与编辑发布配置使用二级页面，不使用巨大弹窗。公开工作流与内部依赖分开表达；输入输出及英文调用定义按需展开，配置值与密钥绑定分开。凭证由全局目录管理，支持全部项目或指定项目，项目发布仅保存凭证引用。全局可用不代表外部调用方获得全部公开能力；调用授权单独限定目标及公开工作流。

表单使用共享 Input、Select、Button 及主题语义令牌。设置分类和模块页签切换保持未保存配置；离开配置页显示内联放弃提示。一次性调用令牌在对话框关闭或离开当前页时清除，不进入浏览器持久存储。回调重试和远程凭证同步使用中性状态，终态错误才使用错误色。

## 画布底部工具栏

工作流顶部仅保留文档级动作：让助手修改、保存、发布、试运行。画布操作集中在画布底部浮动栏，按编辑（添加节点、撤销、重做）、视图（缩小、缩放比例、放大、适应画布）、检查（校验、运行结果）分组；底栏只占用画布区域，不延伸到节点配置面板。结果面板展开时底栏仍在其上方的画布内，关闭结果后焦点返回底栏开关。

底栏复用 surface、border、radius、shadow 和共享按钮、Select 原子组件，不增加原生下拉框或入场动画。缩放比例实时跟随画布手势；缩放按钮与预设直接更新现有编辑器视口，不重建画布。撤销与重做读取编辑器真实历史，禁用无可用历史或正在执行的操作。画布宽度不超过 620px 时隐藏文字；不超过 360px 时视图分组换到第二行，避免挤压控件或覆盖配置面板。

## 归档管理

归档使用侧栏条目的悬停 / 键盘聚焦更多菜单，以及会话、工作流头部的更多菜单，不常驻重复归档图标。菜单共用 `ui/menu-button` 与 `ui/command-menu`；运行状态由后端最终校验。归档当前对象后离开该对象，其他会话与文档保持原状态；工作流先保存草稿，失败时保留编辑现场。

设置提供独立「归档」分类，跨项目展示。搜索、项目选择与刷新位于一行，窄窗口自然换行；类型使用全部 / 会话 / 工作流筛选。列表显示名称、所属项目、类型和时间，右侧分别恢复与彻底删除。恢复是普通操作，删除才使用共享 Button 的 destructive 变体及带范围说明的确认 Dialog，默认焦点在取消。归档空状态、筛选空状态、加载和项目读取失败分别表达；恢复后不抢离设置页面。

## 布局与内容过渡

共享 `ui/presence` 管理进退场、快速重开和可访问性；退出一开始就设置 inert 与 aria-hidden，结束后隐藏或卸载，重新打开取消旧清理。设置、节点库、字段浮层从当前透明度与位移继续过渡，避免中断后重播起点造成闪烁。内容目的地、部署页签与二级配置、节点页签用 200ms 轻淡入，不通过改变 key 重建编辑器、草稿或部署表单。

`ResizablePanel` 对显式开合、分栏和展开编辑使用 300ms 尺寸过渡，关闭期间保留内容尺寸，避免文本不断重排；正常尺寸约束调整即时生效。拖拽开始取消所有尺寸补间，分隔线直接跟手。侧栏、会话、右侧工作台、节点配置、底部结果共用同一规则。已有画布只改变可用空间，保留缩放与位置；新画布若在分栏动画中创建，等待布局稳定后进行唯一一次初始适应，不呈现错误的零宽度视图。

会话过程、工具组、工具详情和节点高级配置用共享 Collapse 进行 200ms 高度折叠；流式内容仍原地追加，不对每个 chunk 或历史条目添加入场动画。关闭的内容退出键盘与读屏导航，最终回复持续可见。浮层与对话框补齐退出动画；居中对话框的布局定位和动画位移分开，退出不偏移居中位置。

系统与应用的减少动态效果同时覆盖 CSS、Web Animations 与延迟卸载；关闭过渡延迟和按压缩放，偏好在动画中变化时立即结束过渡。验收应覆盖连续开合、退场中重开、拖拽中无尺寸补间、设置往返、过程/工具详情展开、已有视口保持以及新画布初次适应。

## 项目列表管理

共享 `ui/select` 的 `EntitySelect` 使用同级的选择按钮与行内更多按钮，避免在可选项中嵌套交互元素。项目菜单支持键盘焦点、Escape 返回和主题一致的浮层；更多菜单与所属浮层共享 ownership，打开子菜单时保持父层。选择项目和管理项目是不同动作，重命名与查看详情不切换工作区或重建画布。

项目详情用共享 Dialog 展示名称、目录、ID、创建时间与数量；路径按需复制或定位，不在侧栏常驻。删除 Dialog 展示项目名称、完整目录和不可恢复范围，必须完整输入名称才启用 destructive 按钮；加载失败和执行冲突就地提示，不自动绕过保护。处理中禁止重复提交或关闭，成功删除当前项目后选择剩余项目，没有项目则展示创建入口。

## 首次空白工作区

首次使用通过普通项目内容展示能力：三个场景项目出现在现有切换列表，各自包含工作流、不同类型的会话、运行和 README 资源。复用项目主页、会话消息流、工具详情与画布，不增加引导专用页面、示例卡片、示例路由或只读分支。会话明确属于预置讲解，实际工具结果与运行快照可展开核实；失败排错保留真实失败与成功的独立记录。

内容采用初始化时的中英文设置，之后作为可编辑项目数据保存。已有工作区与主动清空后的工作区不自动补回项目，避免删除后再次出现。离线流程提供可运行的输入默认值，需模型的工作流在名称和资源说明中明确标注。
